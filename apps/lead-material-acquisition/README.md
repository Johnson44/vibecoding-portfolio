# 手机号留资资料领取站

这是一个面向家长的资料领取落地页：用户选择资料夹、输入手机号并同意隐私说明后，获得资料访问权限。真实版本部署在腾讯云 CloudBase，线索和访问事件写入业务表格，资料文件不直接暴露在前端静态目录中。

## 在线 Demo

[打开领取资料网站](https://zsjohnson.site/lead-material-acquisition/)

## 项目亮点

- 资料卡片、手机号登记、隐私同意和访问解锁形成完整转化链路。
- 前端只提交必要字段，服务端负责限流、线索写入和短期访问凭证。
- 下载接口校验访问凭证；外部云文档采用新窗口打开并记录事件。
- 通过 UTM、来源、提交和下载事件支持后续转化分析。

## 功能说明

- 设计资料领取漏斗：资料选择 → 手机号留资 → 预览 → 下载/打开云文档。
- 实现手机号校验、隐私同意、反爬蜜罐、限流与错误反馈。
- 设计 CloudBase HTTP 函数接口和短期访问 Token，避免把资料文件直接暴露在公开目录。
- 将原始业务资料、企业凭证和真实表格从公开作品集剔除，仅保留脱敏后的流程代码与示例界面。

## 技术栈

真实项目：Next.js / React / TypeScript / CloudBase HTTP 云函数 / 飞书多维表格。

本目录中的源码是脱敏后的可运行流程预览，便于在作品集仓库中展示手机号留资、资料解锁和安全边界；真实部署环境变量不提交到 Git。

## 本地运行

```bash
pnpm install
pnpm dev:lead
```

打开 `http://localhost:5173/`，选择资料卡片即可体验脱敏后的手机号登记流程。线上 Demo 才会连接真实 CloudBase 服务。

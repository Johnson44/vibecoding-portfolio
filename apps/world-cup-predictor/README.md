# 世界杯预测与阵容社区 · World XI Lab

公网入口已与阵容社区合并，统一使用 [世界杯预测与阵容社区](https://zsjohnson.site/world-cup/)；本目录保留为源码入口，不再单独发布。

一个把赛前判断拆解为可解释指标的世界杯产品原型，包含胜率分析、赛事中心、梦幻阵容和阵容社区。

## 在线体验

在线体验：[https://zsjohnson.site/world-cup/](https://zsjohnson.site/world-cup/)。

## 项目亮点

- 以实力排名、近期状态、净胜球和历史交锋构建可复算的加权预测模型。
- 支持主客队切换，并即时更新比分、胜平负概率和赛前简报。
- 提供赛程/赛果、积分榜、阵型选择、预算校验、阵容发布和社区点赞。
- 对演示数据、赛事说明和“非投注建议”边界进行明确标注。

## 我的工作

- 负责预测首页、赛程/赛果、阵容创建和社区发布/排序/点赞等功能开发。
- 设计预测因素、权重展示、阵容规则校验和社区交互流程。
- 将预测结果整理为可继续分发的内容素材，连接产品体验与内容运营场景。

## 技术栈

React 19、TypeScript、Vite、Canvas 分享卡、localStorage、pnpm workspace。

## 本地运行

在仓库根目录执行：

```bash
pnpm install
pnpm dev:world-cup
```

打开 `http://localhost:5174`。

项目仅用于赛事信息和交互展示，不构成投注建议。
